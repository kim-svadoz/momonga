# 하울 릴스 자막 규칙 (초안, 2026-10-25)

> 돈키호테 쇼핑리스트 1탄에서 정한 것을 규칙으로 옮겼다. 사용자 검토 후 확정한다.
> 모양(글꼴·색·위치)은 `brand/style-guide.md`, 만드는 도구는 `tools/haul-reel/README.md`.

## 1. 자막 적는 법 (표기 규칙)

대본을 줄마다 쓰고, **줄 맨 앞 기호**로 자막 종류를 정한다. 기호가 없으면 메인 자막이다.

| 적는 법 | 자막 종류 | 화면 모양 | 예시 |
| --- | --- | --- | --- |
| `#` 제품명 | 제품 제목 | 위쪽, 번호 자동 (1. 2. 3.), 부크크 명조 | `# 치이카와 인형 키링` |
| 그냥 쓰기 | 메인 자막 | 가운데, 흰 글자 + 검정 테두리 | `일본 갔는데 치이카와 못참지..` |
| `!` 문장 | 강조 자막 | 메인 바로 밑, **노랑 손글씨** | `! 이거 진짜 추천해요..` |
| `( 문장 )` | 덧말 | 메인 바로 밑, 노랑 손글씨 **작게** | `(향도 좋아요!)` |
| `*` 문장 | 설명 | 메인 바로 밑, 흰 글자 작게 | `*사루보보 = 일본 행운의 인형` |
| `₩` 제품명 \| 가격 | 가격 | 화면 아래 고정, 작게 | `₩ 모몽가 \| 1,200엔` |
| `₩₩` 문장 | 가격 밑 메모 | 가격 바로 밑, 더 작게 | `₩₩ (나고야 관광지에서 구매)` |
| `/` | 줄바꿈 | 한 자막을 두 줄로 | `수부지 피부라서 / 쌩얼에도 파우더 필수인데` |

- 강조·덧말·설명은 **바로 위 메인 자막과 같이** 나오고 같이 사라진다.
- 가격(`₩`)은 다음 `₩`이 나오거나 다음 제품(`#`)으로 넘어갈 때까지 계속 떠 있다.
- 시간은 적지 않아도 된다. 컷 전환에 맞춰 Claude가 정한다. 꼭 맞추고 싶은 곳만 앞에 `[17.2]`처럼 초를 적는다.

### 대본 예시 (1탄 일부)

```
# 치이카와 인형 키링
일본 갔는데 치이카와 못참지..
복슬복슬 꼬리까지 귀여운 모몽가
₩ 모몽가 | 1,200엔
사루보보ver. 하치와레까지!
*사루보보 = 일본 행운의 인형
₩ 사루보보 하치와레 | 1,540엔
₩₩ (나고야 관광지에서 구매)

# 아누아 아젤라익 세럼
어성초, 티트리 성분 좋아하는 / 민감성 피부라면
! 이거 진짜 추천해요..
₩ 아누아 아젤라익애씨드 15 세럼 30ml | 2,346엔
```

## 2. 썸네일 적는 법

```
[썸네일]
상단: 저장 필수
메인1: n번째 재구매중인
메인2: 돈키호테 쇼핑리스트 1탄
태그: 치이카와굿즈/뷰티템
```

| 줄 | 역할 | 길이 | 모양 |
| --- | --- | --- | --- |
| 상단 | 저장·혜택 유도 한마디 | 6자 이내 | 노랑, `[ ]` 자동 |
| 메인1 | 수식어: 얼마나·누구를 위한 (호기심) | 10자 이내 | 흰색 큰 글씨 |
| 메인2 | 주제 + 시리즈 번호 | 12자 이내 | 노랑 큰 글씨 |
| 태그 | 무슨 제품 리뷰인지 | 12자 이내 | 흰 손글씨 작게, `- -` 자동 |

- 영상 오프닝(0~3.4초)에는 상단·메인1·메인2가 타자기 효과로 나온다. 태그는 썸네일에만 넣는다.
- 배경은 인형·제품 얼굴이 잘 보이는 떼샷 순간. 흔들린 장면이면 밝기만 올린다.

## 3. 문구 쓰는 규칙

| 종류 | 무엇을 쓰나 | 길이 | 개수 |
| --- | --- | --- | --- |
| 메인 | 상황·공감·특징 ("수부지 피부라서 쌩얼에도 파우더 필수인데") | 한 줄 16자 이내, 최대 2줄 | 장면마다 1개 |
| 강조 | 내 실사용 한마디·추천 ("이거 진짜 추천해요..", "다음날 피부결이 진짜 매끈해져요..") | 16자 이내 | 제품당 1개까지 |
| 덧말 | 보너스 정보·감성 ("향도 좋아요!", "선물하기도 좋아요!") | 10자 이내 | 제품당 1개까지 |
| 설명 | 낯선 단어 풀이 ("사루보보 = 일본 행운의 인형") | 20자 이내 | 필요할 때만 |
| 가격 | `제품명 \| 가격`. 영수증 기준, 다른 곳에서 산 건 메모로 | 한 줄 | 제품마다 |

- 말투는 벵짱 말투: 친근한 존댓말 + 끝에 `..`, "진짜", "싹", "찰떡" 등 (`brand/voice.md`)
- 내가 써보지 않은 효과·후기는 쓰지 않는다. 수상 이력은 넣지 않는다.
- 캐릭터별 가격처럼 헷갈리는 가격은 확인 전까지 넣지 않는다.

## 4. 고정으로 들어가는 것 (적지 않아도 자동)

- 맨 위 시리즈 라벨: "돈키호테 쇼핑템 N탄"
- 엔딩: 쇼핑 떼샷 2초 + "곧 N+1탄도 가져올게요!" (부크크 명조) + 별 스티커
- 효과음: 타자기(오프닝) / 클릭(제품 바뀔 때) / 전환음(빈 화면 전) / 딩(첫 강조) / 엔딩 음
