# 스타일 가이드 (폰트·색·썸네일·자막)

> 목표: 폰트 2~3개, 썸네일 템플릿 2~3종으로 고정해서 고르는 시간을 없애고 계정 통일감을 만든다.
> ⬜ 표시는 아직 정하지 않은 칸이다.

## 통일감의 원칙 (벤치마킹 결론)

1. 통일감은 똑같은 이미지가 아니라 **고정된 자리 + 고정된 폰트 + 고정된 색 역할**에서 나온다.
2. 썸네일 문구는 **3단 구조**: 누구를 위한 건지 / 무엇을 주는지 / 혜택
   - 예: "키 160 직장인 / 출근룩 TOP5 / 최저가 링크"
3. 글자는 **화면 정중앙**. 아래쪽은 인스타 버튼·캡션에 가리고, 프로필 그리드에서는 위아래가 잘린다.
4. 색은 3가지 역할만: 메인 글자(흰색) / 강조(⬜) / 포인트 태그(⬜)

## 썸네일 템플릿

| 템플릿 | 용도 | 레이아웃 |
| --- | --- | --- |
| A. 하울형 | 쇼핑하울·모음zip | ⬜ |
| B. 착장 정보형 | OOTD·출근룩 | ⬜ |
| C. 비교·랭킹형 | TOP5, 사이즈 비교 | ⬜ |

참고 공식 (hyuni.ootd):
```
[작은 소제목]  고정 타겟 문구        ← 흰색 굵은 고딕, 매번 같은 문구
[큰 메인제목]  이번 주제              ← 흰색 아주 굵은 고딕 + 어두운 그림자
[아이콘]       쇼핑앱 로고            ← 지그재그·무신사·유니클로 등
[하단 태그]    직접 입어봄 / 최저가 링크  ← 강조색 손글씨체
```

## 영상 자막 규칙

- 위치: ⬜ (기본 제안: 화면 세로 60~70% 지점, 하단 버튼 영역 피하기)
- 한 줄 최대 글자 수: ⬜ (기본 제안: 14자)
- 읽기 좋게: 자간·행간 조절, 그림자 또는 획, 배경 박스로 일부 강조
  - hyuni.ootd: 굵은 손글씨 + 흰색 뿌연 배경 → 어떤 옷 위에서도 잘 읽힘, 보조 자막은 노란 고딕
- 강조 방법: ⬜

## 컬러 팔레트

- ⬜ 3~4색 (메인 / 강조 / 포인트 / 배경 박스)
