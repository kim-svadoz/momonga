# 인스타 피드 글쓰기

먼저 `brand/profile.md`, `brand/style-guide.md`, `brand/voice.md`를 읽는다.

> ⬜ 인스타 계정 주소와 잘 된 게시물 예시가 아직 없다. 받으면 이 파일에 "잘 된 글" 표를 추가한다.

## 캐러셀

- 1장(표지)은 썸네일 템플릿을 쓴다 (`brand/style-guide.md`). 3단 문구, 글자는 정중앙.
- 2장부터: 상품 1개 = 1장. 내 착용 사진 + 짧은 텍스트(상품명·한 줄 특징·가격).
- 마지막 장: 요약 또는 "댓글에 '키워드' 남기면 링크 보내드려요".
- 사진 순서대로 `01_`, `02_` 파일명.

## 캡션

- 첫 줄이 미리보기에 보인다. 훅을 첫 줄에 둔다.
- 본문은 쓰레드보다 짧게. 상품 목록 + 사이즈 정보(`162cm / 49kg 기준`) + 코디 한 줄.
- 댓글 키워드 DM 문구, 제휴 링크 고지.
- 해시태그: ⬜ 고정 해시태그 세트 (브랜드 고정 3~5개 + 주제별 5개 정도로 제안)

## 저장

`output/YYMMDD/insta_<주제>/` 에 `캡션.txt`, 캐러셀 이미지 01~
