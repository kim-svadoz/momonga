# 패션 릴스 만들기

먼저 `brand/profile.md`, `brand/style-guide.md`, `brand/voice.md`를 읽는다. 목표는 **조회수·댓글이 많은 영상 → 팔로우 전환 → 구매 전환**이다.

## 1. 벤치마킹

- 사용자가 준 릴스 링크·스크린샷을 분석해서 `benchmarks/<계정>.md`에 쌓는다.
- 인스타는 로그인 없이 정보가 거의 안 보인다. 화면(썸네일·자막 폰트)은 스크린샷을 받아서 본다.
- 볼 것: 썸네일 공식(문구 구조·위치·폰트·색), 첫 화면 문구(훅), 자막 연출, 좋아요·댓글·저장·공유 비율
  - 댓글 ≫ 좋아요 → 거의 확실히 "댓글 달면 링크 DM" 방식
  - 저장 > 좋아요 → 정보 가치가 높은 영상
- 이미지로는 정확한 폰트 이름을 확정할 수 없다. 비슷한 느낌의 상업용 무료 폰트로 대신 고른다.

## 2. 기획

- **고정 타겟을 시리즈 이름처럼** 쓴다 (`brand/profile.md`의 고정 타겟 키워드).
- 첫 화면 훅 패턴:
  - 부정형 공감: "스트레이트 체형한테 겨울은 최악임"
  - 큐레이션: "내가 여러 개 입어보고 예쁜 것만 골라줌"
  - 숫자·혜택: "블프 때 사야하는 핏 예쁜 바지 추천", "(50% 할인)"
- 시즌·날씨에 맞춘다 (추워지는 시기 → 아우터·니트·가디건).
- 쓰레드에서 반응 좋았던 주제(모음zip, 일본 쇼핑 시리즈)를 릴스로 옮기는 것도 우선 후보.

## 3. 썸네일

`brand/style-guide.md`의 템플릿과 폰트만 쓴다. 정해지지 않았으면 사용자에게 먼저 고르게 한다.
- 3단 문구: 누구를 위한 건지 / 무엇을 주는지 / 혜택
- 글자는 화면 정중앙. 쇼핑앱·브랜드 로고를 스티커처럼 붙이면 무슨 내용인지 바로 안다.
- 작은 괄호 정보 태그로 호기심: "(월 350 이상 버는)", "(50% 할인)"

## 4. 대본·자막

- 대본은 한 문장 = 한 장면. `shortform` 스킬로 편집기에 바로 넣을 수 있게 줄 단위로 쓴다.
- 자막은 `brand/style-guide.md`의 자막 규칙. 기본: 자간·행간 조절 + 그림자/획 + 배경 박스로 일부 강조.

## 5. 캡션과 댓글 DM

- **댓글 키워드 → 링크 DM**을 기본으로 넣는다. 댓글 수와 구매 전환을 한 번에 잡는다.
  - 예: "댓글에 '가디건' 남기면 링크 보내드려요"
  - 자동 DM 도구(ManyChat 같은 서비스)로 자동화할 수 있다. ⬜ 도구 연결 여부
- 제휴 링크 고지 문구를 넣는다.

## 쇼핑 하울 릴스 (돈키호테 N탄, 일본 하울 등)

사용자가 컷 편집한 영상을 주면 **돈키호테 1탄 양식 그대로** 만든다 (2026-10-25 확정).
- 자막 표기·문구 규칙: `brand/caption-rules.md` (사용자가 `!` `( )` `^( )` `[ ]` `*` `₩` `/` 기호로 대본을 주면 그대로 자막 종류를 나눈다)
- 도구와 양식: `tools/haul-reel/README.md`. 예시 결과물: `output/261025/reels_돈키호테 추천템 1탄/기획.md`
- 순서: 컷 순서 파악(`frames.swift`) → 자막표 작성 → `reel.swift` 렌더 → 장면 뽑아서 확인 → 사용자 수정 반영
- 문구는 사용자 실사용 말투로 쓴다 ("이거 진짜 추천해요..", "다음날 피부결이 진짜 매끈해져요.."). 수상 이력은 넣지 않는다.
- 가격은 영수증 기준. 캐릭터별 가격처럼 매칭이 불확실하면 확인받기 전까지 넣지 않는다.

## 피팅 릴스 (매장 피팅 영상으로 추천템 모음, 2026-10-25 자라 맨즈 아우터)

- 도구는 하울 릴스와 같은 `tools/haul-reel/` (아이폰 4K 원본 그대로 됨). 설정은 README의 "패션 피팅 릴스" 열.
- 오프닝: 소개할 착장 전부를 전신 숏컷(0.8초씩)으로 보여주며 훅 문구. 문구는 다 쳐진 뒤 2초 가까이 머물게(오프닝 3초 이상).
- 컷: 한 컷 1~1.4초. 착장마다 전신 → 상반신/포즈 → 디테일(안감·소매) 순. 첫 착장은 반드시 전신부터.
- 베스트샷: `frames.swift`의 화면 변화량이 작은(흔들림 적은) 구간 + 옷 전체·포즈가 보이는 순간.
- 별 스티커 없음, 글꼴 얇게, 제품명은 아래쪽 작게(가격과 한 줄).
- 훅 태그(고정 타겟 키워드)와 맨 위 라벨은 작은 흰 네모 배경(노랑 띠는 밤티, 둥근 알약도 X). 태그는 전신 컷의 가슴 높이. 태그는 큰 제목 바로 위, 오프닝에서 그라데이션으로 닦이듯 등장하고 큰 제목만 타자기.
- 엔딩: "제품명, 가격, 착용 사이즈 등 궁금하신 분들은 / 댓글에 '<키워드>' 남겨주세요".
- 썸네일: 머리 위 큰 브랜드 로고(사람을 오려 얹어 머리가 로고를 살짝 가림, `THUMB_LOGO`) / 큰 제목 두 줄(조선굴림체, 둘째 줄이 더 큼, 예: "자라 맨즈 아우터 / 이건 사지 마세요") / 손글씨 꼬리표(예: "- 두툼한 초겨울 아우터 모음zip. -"). 고정 타겟 태그는 썸네일엔 넣지 않는다. 사진은 따로 찍은 것(`THUMB_IMAGE`), 어둡게는 약하게(`THUMB_DIM=0.15`).
- 제품 정보: 자라 앱 스캔 캡처 → 공식몰에서 이름·가격 확인. 영상 속 택을 확대하면 사이즈·가격을 읽을 수 있다.
