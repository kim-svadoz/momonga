# 블로그 글쓰기 (공통)

네이버 블로그용이면 `naver-blog` 스킬을 쓴다. 이 스킬은 채널을 정하지 않았거나 다른 블로그용일 때 쓴다.

먼저 `brand/profile.md`, `brand/voice.md`를 읽는다.

## 주제 고르기

- 1순위: 쓰레드에서 반응 좋았던 글 (`threads-post` 스킬의 조회수 표)
- 2순위: 시즌·날씨 + 타깃이 지금 살 만한 것 (SPA·컨템포러리·스니커즈·가방)
- 최근 7일 `output/`에 쓴 주제와 겹치지 않게.

## 사실 확인

- 모델명·가격·스펙은 공식 홈페이지 또는 판매 페이지에서 확인한다. 정상가·할인가 둘 다, 확인 날짜도.
- 확인 못 한 숫자는 쓰지 않는다. 보고할 때 "발행 전 확인할 것"으로 따로 알린다.

## 사진

- 내 사진 우선. 상품마다 공식 제품컷 1장.
- 국내 기사 사진, AI 사진은 쓰지 않는다. 출처는 `이미지_출처.txt`에.

## 구매 링크

- 2~3번 반복 (정보 박스 뒤 / 중간 / 마무리 뒤), 앞 문구는 `brand/voice.md`.
- 제휴 링크 고지를 넣는다.

## 저장

`output/YYMMDD/blog_<주제>/`
