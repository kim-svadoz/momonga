# 숏폼 만들기

편집기는 `apps/shorts-editor/`에 있다. 자세한 구조는 그 폴더의 README.

## 실행

```bash
python3 -m http.server 5173 --bind 127.0.0.1
```

저장소 폴더에서 서버를 켠다. Chrome에서 http://localhost:5173/apps/shorts-editor/ 를 연다. 위쪽 **채널** 칸에서 올릴 채널을 고르면 화면 비율·길이 상한·안전 영역이 그 채널 프로필(`channels/<채널>/profile.json`)을 따른다. 작업 내용은 브라우저에 자동 저장된다. 코드를 고친 뒤에는 **Cmd+Shift+R**로 새로고침한다.

## 흐름

1. 대본을 한 문장씩 줄바꿈해서 붙여 넣는다 → 문장마다 장면이 생긴다.
2. 장면마다 영상·사진을 끌어다 놓는다. 영상은 **✂ 영상 자르기**로 필요한 부분만 남긴다.
3. 자막 글꼴·크기는 `brand/style-guide.md`의 자막 규칙을 따른다.
   - 맥에 설치한 폰트(Pretendard 등)는 편집기의 **글꼴 보관함**에 파일로 넣어야 쓸 수 있다.
4. 타이틀(첫 화면 훅)과 효과음을 얹는다.
5. MP4로 내보내고, 프로젝트는 zip으로 저장해서 `output/YYMMDD/reels_<주제>/`에 둔다.

## 알아둘 점

- TTS(목소리 읽기)는 없다. 장면 길이는 글자 수 ÷ 읽는 속도로 정한다.
- 장면이 영상보다 짧으면 "앞 N초만 보여요"가 뜬다. **장면 길이를 영상에 맞추기**를 누른다.

## 편집기 고치기

- 사용자는 코드를 직접 보지 않는다. 고친 뒤에는 실제로 브라우저에서 눌러 보고 확인한 다음 보고한다.
- 고친 내용은 git 커밋으로 남긴다.
