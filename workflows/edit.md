# 목적: 영상편집

사진·영상 원본을 채널에 올릴 영상으로 만든다. 화면 크기, 길이 상한, 자막 위치처럼 채널마다 다른 값은 채널 프로필(`channels/<채널>/profile.json`)과 채널 문서에서 가져온다. 이 문서에는 채널과 무관한 절차만 둔다.

## 입력

- `inbox/<YYMMDD>_<주제>/brief.md`: 채널, 배경설명, 꼭 넣을 말
- 같은 폴더의 영상·사진 원본
- 글을 영상으로 바꾸는 경우에는 `convert` 절차를 먼저 한다.

## 순서

1. `brief.md`에서 채널을 확인한다. 채널 문서와 채널 프로필을 읽는다. 프로필이 없는 채널이면 멈추고 알린다.
2. 원본에서 컷이 바뀌는 지점을 파악한다. 베스트샷을 고른다.
3. 대본을 쓴다. 한 문장이 한 장면이 되게 줄 단위로 쓴다.
4. 훅(첫 화면 문구), 장면별 자막, 썸네일 문구를 정한다.
   - 자막 글꼴·크기·위치와 기호(`!` `( )` `^( )` `[ ]` `*` `₩` `/`)는 `brand/style-guide.md`와 `brand/caption-rules.md`를 따른다.
   - 폰트·음원은 상업적 사용이 가능한 것만 쓴다.
5. 편집 도구로 영상과 썸네일을 만든다. 도구는 채널 프로필을 읽어서 화면 크기와 자막 자리를 정한다.
6. 만든 영상을 실제로 열어서 확인한다. 자막이 잘리거나 가려지지 않는지, 컷이 너무 느리지 않은지 본다.
7. 캡션과 댓글 키워드 DM 문구는 `write` 절차로 만든다.

## 저장

`output/YYMMDD/<채널>_<주제>/` 에 영상, 썸네일, 대본, 편집 프로젝트 파일. 이 폴더는 git에 올리지 않는다.

## 보고에 넣을 것

- 영상과 썸네일의 위치
- 확인하지 못한 것 (예: 원본 파일이 없어서 비교하지 못한 부분)
- 사용자가 직접 할 것 (효과음 넣기, 발행)

발행은 사용자가 직접 한다.
