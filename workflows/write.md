# 목적: 글쓰기

글 채널(네이버 블로그, 쓰레드)과 사진·영상 채널의 캡션·설명글에 쓴다. 채널마다 다른 규격과 말투는 채널 문서에서 가져온다. 이 문서에는 채널과 무관한 절차만 둔다.

## 입력

- `inbox/<YYMMDD>_<주제>/brief.md`: 채널, 배경설명, 꼭 넣을 말
- 같은 폴더의 사진·영상
- 다른 채널 글을 옮기는 경우에는 `convert` 절차를 쓴다.

## 순서

1. `brief.md`에서 채널을 확인한다. 채널 문서의 `## 규격`, `## 말투 차이`, `## 링크·전환 정책`을 읽는다.
2. 주제를 정한다. 이미 정해져 있으면 건너뛴다.
   - 최근 7일 `output/`에 쓴 주제와 겹치지 않게 한다.
3. 사실을 확인한다.
   - 모델명·가격·스펙은 공식 홈페이지나 판매 페이지에서 확인한다.
   - 정상가·할인가를 둘 다 적고 확인 날짜를 붙인다 ("10.20 기준").
   - 확인하지 못한 숫자는 쓰지 않는다. 보고할 때 "발행 전 확인할 것"으로 따로 알린다.
4. 사진을 고른다.
   - 내 사진을 먼저 쓴다. 국내 기사 사진과 AI로 만든 사진은 쓰지 않는다.
   - 사진 출처는 `이미지_출처.txt`에 적는다.
5. 초안을 쓴다. 기본 말투는 `brand/voice.md`, 채널 차이는 채널 문서를 따른다.
   - 내가 겪지 않은 착용감·경험은 지어내지 않는다.
6. 채널 규격을 점검한다. 글자 수는 직접 세어서 확인한다.
7. 저장하고 보고한다.

## 저장

`output/YYMMDD/<채널>_<주제>/` (예: `output/261024/naver-blog_출근룩 가디건/`). 이 폴더는 git에 올리지 않는다.

## 보고에 넣을 것

- 쓴 글의 위치
- 발행 전에 사용자가 확인할 것 (가격, 링크, 재고)
- 채널 규격에서 확인하지 못해 비워 둔 칸

발행은 사용자가 직접 한다. 원고와 사진까지만 준비한다.
