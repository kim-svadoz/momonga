# 채널 × 목적 조합형 콘텐츠 시스템 규격화

## 목적

요청할 때마다 배경과 요구사항을 다시 설명하지 않는다. **어디에 올릴지(채널)**와 **무엇을 할지(목적)**만 정하면, 그 조합에 맞는 규칙·예시·데이터·편집 설정이 항상 같은 방식으로 따라붙게 한다. 입력은 사용자가 주는 사진·영상과 짧은 배경설명뿐이다.

## 범위

이번 작업은 1단계(구조·규격·이관)와 2단계(편집 도구가 채널 프로필을 읽기)를 함께 한다.

- 채널 8개: 네이버 블로그, 쓰레드, 인스타 게시물, 인스타 스토리, 인스타 릴스, 틱톡, 유튜브 쇼츠, 유튜브 롱폼 (REQ-1)
- 목적 3개: 글쓰기, 영상편집, 변환(글→쇼츠, 글→롱폼, 원본 영상→쇼츠/롱폼) (REQ-2)
- 실제로 쓸 수 있게 내용을 채우는 채널: 네이버 블로그, 쓰레드, 인스타 릴스 (REQ-5)
- 나머지 5개 채널은 규격 틀만 만들고 내용은 비워 둔다. 수치를 확인하지 못한 채 채우지 않는다. (REQ-1)
- 편집 도구는 채널마다 따로 만들지 않고, 공통 도구 하나가 채널 프로필을 읽는다. (REQ-7)

## 이번에 하지 않는 것

- 나머지 5개 채널의 내용 채우기
- 롱폼 전용 편집 모듈 (필요 여부는 미결정)
- 발행 자동화. 발행은 계속 사용자가 직접 한다.

## 제약

- 개인 자료(사진·영상·내 글 원본·입력함)는 git에 올리지 않는다.
- 폰트·사진·음원은 상업적 사용이 가능한 것만 쓴다. 기존 공통 규칙은 그대로 지킨다.
- 확인하지 못한 숫자는 쓰지 않는다.
- 옛 스킬 7개는 새 구조가 검증될 때까지 남겨 둔다.
- 이 컴퓨터에는 `output/` 원본이 없다. 실제 영상으로 하는 회귀 검증은 이 컴퓨터에서 할 수 없다.

### REQ-1: 채널 정의

채널마다 규격(화면 비율, 길이, 글자 수, 링크 정책), 말투 차이, 예시, 벤치마킹 자료, 확정된 피드백을 한곳에서 찾을 수 있다. 인스타 릴스와 유튜브 쇼츠는 별도 채널이며 세로 숏폼 공통 규격을 함께 쓴다.

### REQ-2: 목적 정의

글쓰기, 영상편집, 변환 세 목적마다 채널과 무관한 절차가 한곳에 있다. 채널별 세부 규격은 절차에 섞지 않고 채널 정의에서 가져온다.

### REQ-3: 조합 규칙

채널과 목적을 정하면 필요한 문서 묶음이 항상 같은 순서로 조립된다. 같은 채널·목적·입력이면 조립 결과가 매번 같다. 채널·목적 조합이 정의되지 않았으면 빠진 곳을 알려 주고 멈춘다. (AI가 만드는 글과 영상 자체는 매번 같다고 보장하지 않는다.)

### REQ-4: 입력함 양식

사용자는 사진·영상과 짧은 배경설명 양식 하나만 넣으면 된다. 양식에는 채널·목적을 적는 자리와 배경설명 자리가 있고, 입력함은 git에 올라가지 않는다.

### REQ-5: 3개 채널 이관

네이버 블로그, 쓰레드, 인스타 릴스의 기존 규칙·피드백·예시가 새 구조로 옮겨지고, 옮기기 전후로 빠진 규칙이 없다. 옛 스킬의 호출 문구("블로그 글 써줘" 등)가 새 구조에서도 같은 채널·목적으로 이어진다. 옛 스킬은 지우지 않는다.

### REQ-6: 규칙·피드백 분류

시간순으로 섞여 있는 피드백이 채널별, 목적별, 공통으로 나뉜다. 한 규칙이 여러 곳에 중복되어 있으면 한 곳을 기준으로 삼고 나머지는 그곳을 가리킨다.

### REQ-7: 편집 도구가 채널 프로필을 읽기

공통 편집 도구가 채널 프로필(화면 크기, 길이 상한, 자막 안전 영역, 훅 위치, 효과음 규칙)을 읽어서 동작한다. 영상 한 편의 자막·훅·썸네일 문구 같은 회차 데이터는 도구 안이 아니라 별도 데이터로 둔다. 같은 도구에 다른 채널 프로필을 주면 다른 결과가 나온다.

### REQ-8: 원본이 있는 컴퓨터에서 이어서 할 일

`output/` 원본이 있는 컴퓨터에서 처음 pull할 때, 기존 회차(돈키호테 1·2탄, 자라 맨즈 아우터)를 새 형식으로 바꾸고 결과가 기존 영상과 같은지 확인하도록 제안하는 안내가 남아 있다. 이 컴퓨터에서 검증하지 못한 부분은 미검증으로 표시한다.

## 완료조건

1. 채널 8개와 목적 3개가 정의되어 있고, 3개 채널은 내용이 채워져 있다. (REQ-1, REQ-2, REQ-5)
2. 채널 + 목적 조합 결과가 반복 실행에서 같다. (REQ-3)
3. 3개 채널의 기존 규칙이 이관 전후 대조에서 빠짐이 없다. (REQ-5, REQ-6)
4. 편집 도구가 서로 다른 채널 프로필 두 개로 서로 다른 결과를 낸다. (REQ-7)
5. 옛 스킬이 그대로 동작한다. (REQ-5)
6. 원본 컴퓨터에서 이어서 할 일이 문서로 남아 있다. (REQ-8)

## 미결정

- 롱폼에 전용 편집 모듈이 필요한지
- 인스타 스토리·틱톡·유튜브의 공식 규격 수치 (공식 문서로 확인한 뒤에 채운다)
