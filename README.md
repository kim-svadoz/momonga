# momonga

벵짱의 패션 콘텐츠 작업실. 블로그·쓰레드·인스타·릴스·숏폼을 만들 때 Claude가 내 맥락과 규칙을 알고 일하도록 모아 둔 곳이다.

## 쓰는 법

이 폴더에서 Claude Code를 열고 하고 싶은 일을 말하면 된다. Claude가 `CLAUDE.md`를 먼저 읽고 맞는 스킬을 쓴다.

```
cd ~/momonga
claude
```

예: "오늘 쓰레드 글감 하나 줘", "어제 쓰레드 글 네이버 블로그로 옮겨줘", "이 블로그 글 릴스로 만들어줘"

## 구성

| 위치 | 내용 |
| --- | --- |
| `CLAUDE.md` | Claude가 먼저 읽는 안내서 |
| `brand/` | 나·타깃·목표 (`profile.md`), 폰트·색·썸네일 규칙 (`style-guide.md`), 말투 (`voice.md`) |
| `history/` | 결정 기록, 피드백 기록 |
| `benchmarks/` | 벤치마킹 계정 분석 |
| `.claude/skills/` | 채널별 전문 기술 7개 |
| `apps/shorts-editor/` | 브라우저 숏폼 편집기 |
| `output/` | 결과물 (git에 안 올림) |

## 아직 채울 것

`brand/` 파일의 ⬜ 표시: 인스타 계정, 편집 앱, 정돈형/개성형, 고정 타겟 키워드, 폰트 세트 확정, 컬러 팔레트, 해시태그 세트.
