# momonga

벵짱의 패션 콘텐츠 작업실. 블로그·쓰레드·인스타·릴스·숏폼을 만들 때 Claude가 내 맥락과 규칙을 알고 일하도록 모아 둔 곳이다.

## 쓰는 법

이 폴더에서 Claude Code를 열고 하고 싶은 일을 말하면 된다. Claude가 `CLAUDE.md`를 먼저 읽고 맞는 스킬을 쓴다.

```
cd <momonga를 받은 폴더>
claude
```

올릴 **채널**과 할 **일(목적)**을 말하면 된다. 예: "오늘 쓰레드 글감 하나 줘", "어제 쓰레드 글 네이버 블로그로 옮겨줘", "이 블로그 글 인스타 릴스로 만들어줘".
사진·영상이 있으면 `inbox/<날짜>_<주제>/` 폴더에 넣고 `templates/brief.md`를 복사한 `brief.md`에 채널·목적·배경설명을 적는다.

## 구성

| 위치 | 내용 |
| --- | --- |
| `CLAUDE.md` | Claude가 먼저 읽는 안내서 |
| `brand/` | 나·타깃·목표 (`profile.md`), 폰트·색·썸네일 규칙 (`style-guide.md`), 말투 (`voice.md`) |
| `channels/` | 채널별 규격·말투 차이·링크 정책·예시·피드백·편집 설정 (네이버 블로그, 쓰레드, 인스타 릴스는 사용 가능, 나머지는 틀만). 형식은 `channels/README.md`, `channels/profile-schema.md` |
| `workflows/` | 목적별 절차: 글쓰기, 영상편집, 변환 |
| `templates/` | 입력함 배경설명 양식 (`brief.md`) |
| `inbox/` | 사진·영상 입력함 (git에 안 올림) |
| `history/` | 결정 기록, 공통 피드백 기록 (채널별 피드백은 `channels/<채널>/feedback.md`) |
| `benchmarks/` | 벤치마킹 계정 분석 |
| `.claude/skills/` | `studio`(채널 × 목적 조합)와 옛 채널별 스킬 7개 (새 구조가 검증될 때까지 남겨 둠) |
| `tools/` | `compose/` 채널 × 목적 조합기, `haul-reel/` 릴스 자막·썸네일 도구, `migration/` 이관 대조 |
| `docs/` | `원본-컴퓨터에서-이어서.md` — 영상 원본이 있는 컴퓨터에서 처음 pull했을 때 할 일 |
| `apps/shorts-editor/` | 브라우저 숏폼 편집기 (채널 프로필을 읽음) |
| `output/` | 결과물 (git에 안 올림) |

## 아직 채울 것

`brand/` 파일의 ⬜ 표시: 인스타 계정, 편집 앱, 정돈형/개성형, 고정 타겟 키워드, 폰트 세트 확정, 컬러 팔레트.

새 채널(유튜브 쇼츠·롱폼, 틱톡, 인스타 게시물·스토리)과 해시태그처럼 **벵짱이 정해야 할 것**은 `docs/결정할-것.md`에 모아 두었다. 표에서 `⬜ 미정`인 것을 보고 알파벳만 적으면 된다. 인스타그램은 2025-12-18부터 해시태그를 5개까지만 쓸 수 있다.
