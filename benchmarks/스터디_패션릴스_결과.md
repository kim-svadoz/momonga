## 타겟 문구: "2030 사무직 출근룩"보다 콕 집히는 것

잘 된 영상들은 나이·직군보다 **체형 숫자, 취향, 상황**으로 사람을 찍었다.

| 방식 | 실제 예 (반응) | 벵짱 버전 후보 |
| --- | --- | --- |
| 키·몸무게 숫자 | "161cm/53kg 학교 출근" (댓글 8.7천), "159cm 현실핏" | **"162cm 49kg 출근룩"** |
| 체형 | "스트레이트 체형"(hyuni.ootd), "통통 직장인"(51만) | "162 마른 직장인" / ⬜ 실제 체형 타입 확인 필요 |
| 명품 맛 SPA | "르메르맛 유니클로"(댓글 4.5천), "생로랑·르메르 맛 자라" | **"명품맛 SPA"** |
| 취향 | "깔끔 담백 취향"(댓글 3천), "추구미가 매일 바뀌는 여성" | "미니멀 취향 출근룩" |
| 현실·돌려입기 | "돌려입기"(46만), "찐 현실" | "돌려입는 출근룩" |

**추천: 소제목 고정을 "162cm 49kg 출근룩"으로.**
- 근거 1: 댓글 1위 영상이 똑같은 공식(키/몸무게 + 출근)이었다.
- 근거 2: 같은 키의 사람이 "내 얘기다" 하고 사이즈 참고하러 저장·팔로우한다. "2030 사무직"은 너무 넓어서 그런 반응이 안 생긴다.
- 근거 3: 프로필에 이미 있는 실제 정보라 지어낼 게 없다.
- 보조로 "명품맛 SPA"를 제목 쪽에 섞으면 자라·유니클로 영상에 잘 맞는다.
