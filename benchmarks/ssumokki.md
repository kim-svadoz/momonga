# ssumokki (이수목) — 폰트만 고정한 개성형

분석일: 2026-10-24 (사용자가 준 스크린샷 + 릴스 링크 기준)

## 썸네일

- 모든 썸네일에 **좁고 길쭉한 장체 고딕** 하나만 쓴다. 색은 형광 분홍·노랑·하늘색·흰색으로 매번 바뀌어도 폰트가 같아서 통일감이 있다.
- 문구 구조: **작은 수식어 + 큰 메인 문구**
  - "색감 끝내주는 / 가디건 추천", "블프 때 사야하는 / 핏 예쁜 바지추천"
- 브랜드 로고(UNIQLO, MUJI, MUSINSA, 직잭팍)를 스티커처럼 붙여 무슨 내용인지 바로 알게 한다.
- "(50% 할인)", "(월 350 이상 버는)" 같은 작은 괄호 정보 태그로 호기심을 만든다.
- 얼굴과 표정이 나와서 사람 자체의 매력으로 팔로우를 모은다.

## 수치

- 조회수 1위(10.4만): "색감 끝내주는 가디건 추천 + 유니클로 로고" 썸네일
- 유니클로 가을 니트·가디건 추천 영상: 좋아요 307, 댓글 13, **저장 428** → 저장이 좋아요보다 많음 = 정보 가치가 높다는 신호

## 연출

- 캡션: **"댓글에 '수목' 남기면 링크 보내드려요"** — 댓글 수와 구매 링크 전달을 한 번에.
