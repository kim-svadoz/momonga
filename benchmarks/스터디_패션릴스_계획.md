# 패션 릴스 스터디 계획 (2026-10-25 요청, 진행 전)

돈키호테 하울 다음으로 올릴 **패션 릴스**를 위해 인스타·유튜브 쇼츠를 공부한다.
크롬 확장(Claude in Chrome)이 연결된 새 대화에서 이 파일을 읽고 바로 시작한다.

## 내가 가진 영상 소스

1. 자라 맨즈 아우터 추천 (SPA 피팅룸 촬영샷, 있음)
2. 지그재그 10월 잘산템 (촬영 예정)
3. 오오티디 모음집 (있음)

## 알고 싶은 것

- 위 주제를 주로 다루는 인스타 패션 계정의 영상 트렌드, 편집 스타일
- **초반 3초 훅**과 조회수를 높이는 방법
- 잘산템·오오티디 모음은 구매 전환에 유리 → **댓글이 유독 많은 영상**을 골라 댓글 유도·DM 방식을 본다
- 지금 키워드 "30대 직장인" / "2030 사무직 출근룩"이 타겟팅이 아쉬움 → 더 콕 집히는 **타겟 문구·마케팅 포인트** 찾기

## 진행 방법

- 사용자 크롬(인스타 로그인 상태)으로 계정·릴스를 보며 조회수·댓글·첫 3초 화면을 모은다. 보기만 하고 좋아요·팔로우·댓글은 누르지 않는다.
- 유튜브 쇼츠도 같은 주제로 같이 본다.
- 계정 하나 = `benchmarks/<계정>.md`, 위 README 표에 한 줄 추가.

## 결과물

- 주제별(자라 아우터 / 지그재그 잘산템 / 오오티디 모음) 훅 문구, 썸네일 문구, 댓글 유도 문구 초안
- 타겟 문구 후보와 근거 → 정해지면 `brand/profile.md`의 고정 타겟 키워드 갱신
