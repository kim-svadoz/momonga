# hyuni.ootd — 레이아웃까지 고정한 정돈형

분석일: 2026-10-24 (사용자가 준 스크린샷 기준)

## 썸네일 공식 (거의 모든 게시물이 같음)

```
[작은 소제목]  스트레이트 체형        ← 흰색 굵은 고딕, 매번 같은 문구
[큰 메인제목]  겨울 아우터 추천       ← 흰색 아주 굵은 고딕 + 어두운 그림자
[아이콘]       분홍 Z 로고            ← 지그재그 앱 로고
[하단 태그]    직접 입어봄 / 최저가 링크  ← 노란 손글씨체
```

- 글자는 화면 정중앙에만. 프로필 그리드에서 위아래가 잘려도 제목이 다 보인다.
- 색은 흰색, 노란색, 분홍 로고 세 가지만.
- 사진은 매번 달라도 글자 위치·폰트·색이 같아서 계정 전체가 하나의 브랜드처럼 보인다.

## 영상 수치

- 좋아요 651, **댓글 4,175**, 공유 1,243
- 댓글이 좋아요의 6배 → 거의 확실히 "댓글 달면 링크 보내드림" 방식

## 연출

- 첫 화면: **"스트레이트 체형한테 겨울은 최악임"** — 특정 체형의 불편함을 건드리는 부정형 훅
- 자막: 굵은 손글씨체 + 뒤에 흰색 뿌연 배경 → 어떤 옷 위에서도 잘 읽힘. 보조 자막은 노란 고딕.

## 배울 점

"스트레이트 체형"이라는 **고정 타겟을 시리즈 이름처럼** 쓴다. 같은 체형인 사람은 "이 계정은 내 얘기구나" 하고 팔로우한다.
