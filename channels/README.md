# 채널

콘텐츠를 올리는 곳마다 폴더 하나를 둔다. 채널을 정하면 그 채널의 규격·말투·예시·피드백이 한곳에서 나온다.

## 채널 목록

| 폴더 | 이름 | 계열 | 상태 |
| --- | --- | --- | --- |
| `naver-blog` | 네이버 블로그 "맛따라 멋따라" | 글 | 사용 가능 |
| `threads` | 쓰레드 | 글 | 사용 가능 |
| `insta-reels` | 인스타 릴스 | 숏폼 | 사용 가능 |
| `insta-post` | 인스타 게시물 | 사진 | 틀만 |
| `insta-story` | 인스타 스토리 | 스토리 | 틀만 |
| `tiktok` | 틱톡 | 숏폼 | 틀만 |
| `youtube-shorts` | 유튜브 쇼츠 | 숏폼 | 틀만 |
| `youtube-long` | 유튜브 롱폼 | 롱폼 | 틀만 |

- **사용 가능**: 규칙·예시·피드백이 채워져 있다.
- **틀만**: 섹션만 있고 내용은 `⬜`다. 공식 문서로 확인하기 전에는 수치를 채우지 않는다.
- 인스타 릴스와 유튜브 쇼츠는 같은 세로 영상이지만 링크·DM 정책, 캡션, 해시태그가 달라서 채널을 나눴다.

## 채널 폴더 구성

| 파일 | 내용 | 필수 |
| --- | --- | --- |
| `channel.md` | 규격, 말투 차이, 링크·전환 정책, 예시 | 필수 |
| `feedback.md` | 이 채널에만 해당하는 확정 피드백 | 사용 가능 채널만 |
| `profile.json` | 편집 도구가 읽는 화면·길이·자막 설정 | 영상 채널만 |

### channel.md의 틀

맨 위 머리말과 아래 여섯 섹션을 항상 같은 순서로 쓴다. 조합기가 이 틀을 보고 빠진 곳을 알려 준다.

```
---
id: <폴더 이름>
name: <채널 이름>
family: 글 | 사진 | 스토리 | 숏폼 | 롱폼
status: 사용 가능 | 틀만
purposes: [write, edit, convert 중 이 채널에서 하는 것]
---

## 역할
## 규격
## 말투 차이
## 링크·전환 정책
## 예시
## 참고
```

- `## 규격`: 비율, 길이, 글자 수, 해시태그 수처럼 숫자로 정해진 것. 확인 날짜를 붙인다.
- `## 말투 차이`: `brand/voice.md`의 기본 말투와 다른 점만 쓴다. 같은 내용을 다시 쓰지 않는다.
- `## 링크·전환 정책`: 링크를 어디에 두는지, 댓글 키워드 DM을 쓰는지, 제휴 고지 문구.
- `## 예시`: 잘 된 글·영상과 그 이유. 근거가 되는 날짜와 수치를 붙인다.
- `## 참고`: 벤치마킹 자료(`benchmarks/`)와 옛 스킬 위치.

## 계열별 공통 규격

계열이 같은 채널은 아래 공통 규격을 함께 쓴다. 채널 문서에는 공통과 다른 점만 쓴다.

### 숏폼 (인스타 릴스, 틱톡, 유튜브 쇼츠)

- 화면: 세로 9:16, 1080×1920 (이 저장소의 릴스 도구가 이미 쓰는 값)
- 대본은 한 문장이 한 장면이 되게 쓴다.
- 첫 화면에 훅 문구를 둔다. 글자는 화면 정중앙에 가깝게 둔다.
- 영상 길이 상한, 안전 영역, 해시태그 수는 채널마다 다르므로 각 채널 문서의 `## 규격`에서 확인한 값만 쓴다.

### 글 (네이버 블로그, 쓰레드)

- 확인하지 못한 숫자(가격·스펙·조회수)는 쓰지 않는다. 가격은 확인 날짜를 붙인다.
- 내가 겪지 않은 착용감·경험은 지어내지 않는다.

### 사진, 스토리, 롱폼

- ⬜ 확인된 공통 규격이 아직 없다. 채널 문서가 채워질 때 같이 정한다.

## 입력함

사용자가 주는 사진·영상과 배경설명은 `inbox/<YYMMDD>_<주제>/` 폴더에 둔다. `templates/brief.md`를 복사해 `brief.md`로 쓴다. `inbox/`는 git에 올리지 않는다.
